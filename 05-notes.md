# Procedure 4 · Draft the meeting notes

**Input.** The transcript export from the meeting tool, with any names you do not want recorded removed.
**Output.** A one-page note.

## Prompt

```prompt
Convert the attached meeting transcript [transcript.docx] into a one-page working-meeting note for an Epic build project. Structure: a header table (date, duration, attendees as given, focus); Background (2 to 3 sentences); Key decisions (bullets, one decision each); Open questions (bullets); Next actions (bullets, each starting with a name); Artifacts reviewed (files, screenshots, versions). Past tense, neutral tone. Do not add decisions that are not in the transcript; put undecided topics under Open questions. Under 400 words. No patient information.
```

## Check

Read the Key decisions against your memory of the meeting before circulating. Edit by hand; the draft is a starting point.
