# Procedure 4 · Draft the meeting notes

**Input.** The transcript export from the meeting tool, with names removed as required.
**Output.** A one-page note.

## Prompt

```prompt
Convert the attached meeting transcript [transcript.docx] into a one-page working-meeting note for an Epic build project. Structure: a header table (date, duration, attendees as given, focus); Background (2 to 3 sentences); Key decisions (bullets, one decision each); Open questions (bullets); Next actions (bullets, each starting with a name); Artifacts reviewed (files, screenshots, versions). Past tense, neutral tone. Include only decisions present in the transcript; place undecided topics under Open questions. Under 400 words. Exclude patient information.
```

## Check

Compare the Key decisions with the meeting before circulating the note. Edit the draft by hand.
